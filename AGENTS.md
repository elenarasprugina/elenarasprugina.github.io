# 13mirrors.ru · главная — правила для любого ИИ-помощника

Это главная страница сайта 13mirrors.ru (`index.html`, `/grimoire/`, `/privacy/`, копия `/13mirrors-blue-hand/`).
Все правила владелицы и устройство проекта — в репозитории **`elenarasprugina/vitrina`**:
`AGENTS.md`, `CLAUDE.md`, `docs/status.md` (шпаргалка, читать первой) и `docs/handover.md` (передача дел).

Коротко:
- Владелица — психолог, не программист: пиши ей по-русски и просто. «Обсуждаем» / «стоп» — ничего не меняй.
- Тексты, картинки и контакты главной она меняет в панели витрины (`13mirrors.ru/vitrina/admin/`, раздел «Главная страница»);
  страница берёт их из `vitrina/data/settings.json`. Здесь — только код и оформление.
- **Не удалять `CNAME`.** Не добавлять аналитику, счётчики, формы, внешние шрифты и скрипты (шрифты — из `vitrina/assets/fonts/`).
- Работай в своей ветке, в `main` не вливай: вливает она сама. После влития GitHub Actions «Пересылка на REG.RU»
  (`.github/workflows/deploy-regru.yml`) копирует файлы в корень сайта, папку `vitrina/` не трогает.
- Код — ES5, без сборщиков. Проверяй на телефоне 390 px и компьютере 1366–1440 px.
